# Anonymous review release

The research repository is organized without author names, affiliations, contact emails or identifying file paths. Use an anonymous read-only repository mirror as the URL in a two-way anonymized review submission.

The repository contains executable source, public dependency references, model/configuration adapters, and a small self-contained KG example. Benchmark data and downloaded model weights are provided separately through their official owners and model hubs.

A public repository can be mirrored at https://anonymous.4open.science/ . Configure the mirror and use its anonymous `/r/...` URL in the submission, rather than the URL displaying the personal GitHub username.
